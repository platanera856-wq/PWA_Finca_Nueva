# Lista de pruebas de aceptación

Marcar cada punto solo después de probarlo en el teléfono físico.

- [ ] La app abre por HTTPS y se puede instalar en Chrome Android.
- [ ] Los archivos principales se cargan después de la primera visita con internet.
- [ ] Se guarda un registro ficticio en IndexedDB.
- [ ] El registro sigue visible después de cerrar y volver a abrir la app.
- [ ] La app abre en modo avión tras haberse cargado antes.
- [ ] Se puede crear y conservar un registro sin conexión.
- [ ] Se exporta una copia JSON y el archivo se puede abrir.
- [ ] Se revisan los permisos y el inicio/cierre de cámara.
- [ ] Se integra y prueba lectura QR con biblioteca local.
- [ ] Se integra y prueba reconocimiento de voz español sin conexión.
- [ ] Se verifican catálogos y caballones reales.
- [ ] Se prueba sincronización con Apps Script y se verifica que no haya duplicados.
- [ ] Se valida regla de inventario: cantidad mayor al stock debe avisar por voz y bloquear el envío hasta corregirla.
